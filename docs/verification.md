- 分支必须手选；缺少选择时播放暂停，不自动走“正常分支”。

- try-else 抛出异常不会被同一 try 的 handler 重新捕获；跨函数异常向上传播。
- switch 的 break 限于 switch；JS 解析器保留 case fallthrough。
- 跳过、跳出函数、类、模块都服从内部断点；跨文件进入时定位被调用函数的定义。
- 在分支暂停后恢复跳出操作，仍以原调用实例为目标。
- 回退改选后切除旧路径未来；场景 JSON 回放到同一游标。
- 场景与源码快照绑定；错误快照和不完整记录拒绝恢复。
- 场景保存的展开配置独立复制；更改深度会重置当前路径，恢复场景时同步对应配置，避免中途改配置破坏回放。

- 不执行扫描源码；索引目录之外的软链接源码不读取；索引过期边降为候选。
- LSP 通过实际 stdio 子进程和 Content-Length 消息交换测试：别名调用通过语义调用点映射到本地函数；同一行不同位置不得混配。
