## 行为与设计

在现有工作区增加三图投影。借鉴 Archify 的可读节点、分组、语义色、端口、折线路由、生命线、缩放和明暗主题；本次是把数据驱动的 SVG 绘图集成到应用，使用其 authoring defaults 指导信息与几何设计，不把应用数据伪称为已通过 Archify finalize 的独立候选。

- 全景图：按源码文件分组，类聚合其方法、顶层函数聚合闭包；调用证据按符号归属聚合，候选保持虚线和来源说明。大图分页明确数量，底层符号不删除。
- 时序图：只使用播放器当前游标之前的 enter/leave 等记录，生命线按调用实例区分递归；退出后才画返回。选择与边界保留。尚未演示时给出入口选择，不从静态边猜测次序。不模拟并发时钟。
- 流程图：从统一 Flow operation 构建图，条件分叉、循环回边、退出、异常处理与 finally 路由保留；不按邻居排序编造流程。未知或未适配处显示边界。
- 点击图中符号／步骤，同步树、源码及说明；时序记录可定位到对应教学事件。三图支持缩放、适应画布与 SVG 导出，明暗主题与离线可用。
- 保留路径演示、结构地图和调用邻域，旧函数流程的重复列表由图形投影替换。

## 解释范围

时序图为手动假设记录，不表示目标项目真实运行或并发耗时。函数流程是适配器模型的可能路径，不证明运行输入可行。图表参考 Archify 的视觉与布局规则，实际使用 repo2tree 自有模型／SVG，不生成 Archify candidate，也不声称执行其 finalize。

浏览器实测限本机 Chrome；跨浏览器、超大型仓库帧率与内存仍未全面验证。大图分页不删除底层数据；当前页以外节点之间的连线需切页或通过调用邻域查看。5000步测试只证明线性渲染不栈溢出，不是浏览器大函数性能基准。
